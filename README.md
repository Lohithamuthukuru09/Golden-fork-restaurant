# The Golden Fork 🍴

A modern, responsive single-page restaurant & café website with an interactive menu, table booking, and a unique "Fruit Promise" feature.

![Tech](https://img.shields.io/badge/HTML-CSS-JS-blue)

## ✨ Features

- **Responsive Design** — looks great on mobile, tablet, and desktop
- **Interactive Menu** — filter dishes by category (Starters, Mains, Desserts, Drinks)
- **Table Booking Form** — with instant confirmation message
- **Fruit Promise Banner** — a free seasonal fruit with every visit
- **Photo Gallery** — hover effects on dish images
- **Location Section** — embedded Google Map + opening hours
- **Smooth Scrolling & Mobile Navigation** — hamburger menu for small screens

No installation needed! Just open `index.html` in your browser.
